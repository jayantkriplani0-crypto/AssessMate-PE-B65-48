## Project Overview
AssessMate converts syllabus topics, syllabus excerpts, learning outcomes, and Revised Bloom's taxonomy levels into structured exam questions, model answer keys, and stepwise marking schemes, then runs an independent reviewer prompt to audit clarity, syllabus relevance, answerability, Bloom's alignment, answer accuracy, mark consistency, and difficulty before teacher approval.
